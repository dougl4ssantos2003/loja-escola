# Gemialidades Weasley — Loja Impossível

## Sobre o projeto

A **Gemialidades Weasley** é uma loja fictícia inspirada no universo de Harry Potter, desenvolvida como parte do projeto acadêmico Loja Impossível. O site apresenta produtos mágicos e invenções divertidas em uma interface temática, responsiva e interativa.

O objetivo é praticar HTML, CSS e JavaScript por meio do desenvolvimento de um catálogo de produtos, páginas de detalhes e um fluxo de compra simulado.

## Tecnologias utilizadas

- **HTML5:** estrutura e organização das páginas.
- **CSS3:** identidade visual, estilos personalizados e responsividade.
- **JavaScript:** carregamento dos produtos, filtros, ordenação e validações.
- **Bootstrap 5:** componentes e layout responsivo.
- **JSON:** armazenamento dos dados do catálogo.
- **ViaCEP:** consulta de endereço pelo CEP.
